# Third-party component notices

## 21st.dev changelog pattern

SpotFinder's `ReleaseTimeline` adapts the semantic release-list pattern from **What's New Changelog Timeline** by DHxWhy, discovered in the 21st.dev catalogue:

- Source catalogue page: https://21st.dev/@dhxwhy/components/changelog-timeline
- Catalogue license: MIT License
- Adopted ideas: chronological release rail, clear dated entries, category labels, keyboard-readable static content, light/dark styling, and reduced visual motion.
- Not copied: the demo's autoplay, pointer simulation, live deployment status, hover-to-expand behavior, or sample CCgather content.

The adapted SpotFinder component uses only existing `react`, `lucide-react`, and Tailwind dependencies and makes no network requests.
