# SpotFinder work instructions

- Implement only the task requested. Keep the existing production SpotFinder app unchanged.
- Scope redesign changes to `/new` and its isolated components and styles.
- Inspect only files relevant to the task. Preserve working features and use existing services.
- Do not run Playwright, browser automation, screenshot testing, end-to-end tests, or visual tests.
- Do not install dependencies unless necessary.
- Do not repeatedly run build, lint, or test commands. Run at most one targeted validation command only if necessary; otherwise report that validation was skipped.
- Do not deploy, modify Firebase infrastructure, change environment variables, or alter production Firestore schema or security rules.
- Do not refactor unrelated code.
- Finish with a concise summary of changed files, completed work, and blockers.
